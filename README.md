
# SENTINEL 🛡️

### Security Monitoring and Threat Detection Platform

Sentinel is a Python-based security monitoring platform designed to analyse authentication logs, detect suspicious login activities and generate security alerts.

## Tech Stack
- Python
- FastAPI
- SQLite
- React
- Git & GitHub

## Features
- Authentication log analysis
- Brute-force attack detection
- Suspicious IP identification
- Security alert management
- Interactive monitoring dashboard
